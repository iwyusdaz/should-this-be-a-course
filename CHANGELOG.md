# Changelog

All notable changes to this project are documented here.
Format based on Keep a Changelog; versioning is date-based for a portfolio project.

## [1.0.0] — 2026-10-25

### Added
- Full performance consulting case study for the fictional organization **Brightline Health Services**: intake, discovery, root-cause analysis, solution design, build, and measurement plan (`docs/`).
- Simulated evidence set, labeled as constructed for portfolio purposes: completed intake form, 6 interview notes, a 200-row survey CSV generated by a seeded script (`scripts/generate-survey.mjs`), and fictional HR documents.
- Root-cause analysis using Gilbert's Behavior Engineering Model and a Mager & Pipe decision flow (Mermaid).
- Solution design: action map, stakeholder proposal, solution blueprint, and "What we won't build".
- Branching scenario (Twine/SugarCube 2.37.3, compiled with Tweego 2.1.1) with 3 decision points, 3 endings, consequence-based feedback, keyboard support and focus management (`docs/05-build/scenario/`); Twee source kept in `src/scenario.twee`.
- "Feedback in 5 minutes" job aid (accessible HTML + tagged PDF) and a 30-day manager practice challenge.
- Measurement plan with leading/lagging indicators and a simulated baseline dashboard.
- Evaluation infrastructure:
  - Scripted Playwright tests of the scenario (keyboard-only playthrough, 320 px reflow, 400% zoom, focus management, step counts) with committed results.
  - `ariaSnapshot()` capture as the screen-reader-output fallback (Guidepup/VoiceOver automation is not supported on the build machine's macOS version).
  - Pending API pipelines `evaluation/run-simulations.mjs` (simulated learner runs with a >75% same-choice revision flag) and `evaluation/run-review-panel.mjs` (multi-model structured review), both with `--dry-run` modes; run via `npm run eval:pending`.
  - Human testing protocol (consent text, test script, findings template, structured review form, manual VoiceOver check) in `evaluation/human-protocol/`.
- Accessibility verification: axe-core audits and scripted keyboard/reflow tests; results in the README accessibility statement and `docs/06-measure/usability-test-report.md`.
