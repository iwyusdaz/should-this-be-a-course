## How to run the pending evaluations

1. Copy `.env.example` to `.env` and fill in at least `MODEL_A_*` and `MODEL_B_*` (OpenAI-compatible endpoints).
2. `npm run eval:dry-run` — verify the pipelines end-to-end with stub data (writes to `dry-run/`, never cited as evidence).
3. `npm run eval:pending` — real runs; results land in `evaluation/simulation-results/` and `evaluation/panel-results/`; `evaluation/results.md` is regenerated by the pipelines.
4. Update the evaluation-status line in `README.md`, section 1 of `evaluation/METHODS.md`, `docs/06-measure/usability-test-report.md` and this file from the run summaries.
